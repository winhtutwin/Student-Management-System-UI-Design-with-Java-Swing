This is a clean and functional User Interface (UI) design for a Student Management System, built using Java Swing. It provides a structured GUI layout for inputting and viewing student records.

🛠️ How to Run
If you are using the terminal (Command Prompt/Terminal), follow these steps:

1. Compile the code:
javac StudentManagementGUI.java

2. Run the application:
java StudentManagementGUI
